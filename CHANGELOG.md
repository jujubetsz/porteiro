## [0.2.0](https://github.com/jujubetsz/porteiro/releases/tag/v0.2.0)

### Features

- Add collapsible host groups, tags and colors through SSH config comments.
- Search group names and tags, preserve expansion on reload, and show
  configuration warnings in an overlay.
- Display the running version in the header, including narrow layouts and
  overlays.
